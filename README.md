| مورد | آدرس |

- **بدون آی‌پی و بدون سرور محلی** — هر جا اینترنت باشد، سیستم در دسترس است؛ فقط نام کاربری و رمز عبور.
- **همگام‌سازی کامل**: هر ثبت (نمره، حاضری، شاگرد، کتاب...) بلافاصله به مخزن دادهٔ ابری می‌رود و برای همهٔ دستگاه‌ها در سایت و اپ یکسان دیده می‌شود.
- **آفلاین**: آخرین داده‌ها روی دستگاه کش می‌شود؛ ثبت‌های آفلاین در صف می‌مانند و با وصل شدن اینترنت خودکار همگام می‌گردند.
- **APK اندروید**: رابط کاربری داخل خود اپ جاسازی شده — حتی بدون اینترنت باز می‌شود؛ فقط همگام‌سازی اینترنت می‌خواهد.

### اولین اتصال (فقط یک بار برای هر دستگاه)
- **APK خصوصی مکتب**: توکن داخل اپ جاسازی شده — نصب کنید و مستقیم با یوزر/پسورد وارد شوید (صفر پیکربندی).
- **وب‌سایت**: در صفحهٔ ورود، بخش «اتصال ابری گیت‌هاب» را باز کنید و توکن مخزن داده را یک بار وارد کنید. توکن تنها در همان دستگاه ذخیره می‌شود.
- توکن = توکن گیت‌هاب با دسترسی خواندن/نوشتن مخزن `nedaalqalam-school-data`. مدیر می‌تواند از **تنظیمات → اتصال ابری** آن را در هر زمان عوض کند.

> 🔐 **توصیهٔ امنیتی**: برای اتصال ابری از یک توکن **Fine-grained** محدود به همان مخزن داده (Contents: Read/Write) استفاده کنید و توکن اصلی خود را هرگز در اختیار عموم نگذارید. سابقهٔ کامل تغییرات در تاریخچهٔ (commit) مخزن داده حفظ می‌شود و پشتیبان‌گیری/بازیابی از تنظیمات اپ امکان‌پذیر است.

## ✨ امکانات

### نقش‌ها و دسترسی‌ها
| نقش | دسترسی |
|---|---|
| **مدیر** | دسترسی کامل: صنف‌ها، مضامین، معلمان، کارمندان، کاربران، گزارش‌ها، تنظیمات، پشتیبان‌گیری، اتصال ابری |
| **سرمعلم** | نظارت بر حاضری معلمان و شاگردان، تقسیم مضامین، تایید نمرات |
| **معلم** | حاضری صنف، ثبت فعالیت و نمرات مضمون خودش |
| **شاگرد / سرپرست** | مشاهدهٔ نمرات، حاضری، فعالیت‌ها و نتیجهٔ نهایی |
| **ملازم / کارمندان** | حاضری و وظایف محول‌شده |
| **کتابخانه** | ثبت کتاب‌ها، امانت دادن و پس گرفتن، تاریخ برگشت |

> 🔒 اگر مدیر یک کاربر را **غیرفعال یا حذف** کند، آن شخص دیگر نمی‌تواند وارد شود (نشست او نیز باطل می‌گردد).

### بخش‌های اصلی
- **صنف اول تا دوازدهم** + نگران صنف + تقسیم مضامین به معلمان
- **حاضری یومیه**: حاضر / غایب / مریض / رخصت + **گزارش ماهانه** با چاپ و Excel + اعلان غیبت به سرپرست
- **حاضری معلمان و کارمندان** با نظارت سرمعلم
- **فعالیت شاگردان**: کارخانگی، رفتار، شرکت در درس + امتیاز
- **نمرات**: تحریری، تقریری/عملی، کارخانگی، فعالیت صنفی برای دو دورهٔ **چهارونیم‌ماهه** و **سالانه** + تایید سرمعلم
- **جدول نتایج خودکار**: همهٔ مضامین هر شاگرد در یک جدول با **مجموع، اوسط (دو رقم اعشار)، رتبه در صنف و نتیجه** — نمره‌ای که معلم ثبت می‌کند به‌صورت خودکار در جدول صنف و کارنامهٔ شاگرد منعکس می‌شود
- **کارنامهٔ دیجیتال** هر شاگرد با چاپ (PDF)، خروجی **Word** و **Excel**
- **کتابخانه**: کتاب‌ها، امانت، پس گرفتن، تاریخ برگشت و هشدار تأخیر
- **اعلان‌ها** برای معلمان و والدین (غیبت، تایید نمرات، اعلان دستی)
- **پشتیبان‌گیری (Backup)** و بازیابی — بازیابی تنها برای مدیر

### نتیجهٔ خودکار
| نمرهٔ نهائی | مکتسبه |
|---|---|
| ۹۰ تا ۱۰۰ | الف |
| ۸۰ تا ۹۰ | ب |
| ۷۰ تا ۸۰ | ج |
| ۶۰ تا ۷۰ | د |
| ۵۰ تا ۶۰ | هـ |
| زیر ۵۰ | **تکرار صنف** |

نمرهٔ نهائی هر مضمون = میانگین نمرهٔ چهارونیم‌ماهه و سالانه. اگر در یک مضمون نمرهٔ کمتر از ۵۰ باشد، نتیجهٔ کل شاگرد «تکرار صنف» می‌شود.

## 🗂 ساختار پروژه (کامل)

**تمام بخش‌های اپ در این مخزن موجود است** — ۱۷ ماژول رابط کاربری، لایهٔ دادهٔ ابری و همهٔ ابزارها:

### رابط کاربری — `src/components/app/`
| فایل | بخش |
|---|---|
| `login-view.tsx` | صفحهٔ ورود + بوت‌استرپ اتصال ابری |
| `dashboard-view.tsx` | داشبورد: آمار زنده، حاضری امروز، تقویم شمسی |
| `students-view.tsx` | ثبت و ویرایش شاگردان |
| `teachers-view.tsx` | معلمان و کارمندان |
| `classes-view.tsx` | صنف‌ها و تقسیم مضامین به معلمان |
| `subjects-view.tsx` | مضامین درسی |
| `attendance-view.tsx` | حاضری یومیه + ماهانه + حاضری کارمندان |
| `activities-view.tsx` | فعالیت شاگردان |
| `grades-view.tsx` | ثبت نمرات چهارونیم‌ماهه و سالانه |
| `results-view.tsx` | جدول نتایج و کارنامه |
| `library-view.tsx` | کتابخانه |
| `users-view.tsx` | کاربران و دسترسی‌ها |
| `tasks-view.tsx` | وظایف کارمندان |
| `settings-view.tsx` | تنظیمات + اتصال ابری + پشتیبان‌گیری |
| `about-view.tsx` | دربارهٔ اپ و سازنده |
| `app-shell.tsx` | قاب اپ: منو، هدر، اعلان‌ها |
| `ui-bits.tsx` | اجزای مشترک |

### لایهٔ دادهٔ ابری — `src/lib/client/`
| فایل | وظیفه |
|---|---|
| `gh.ts` | ارتباط با GitHub Contents API: خواندن با کش/ETag، نوشتن با SHA و حل تضاد همزمانی |
| `backend-common.ts` | رمز scrypt (سازگار WebCrypto)، نشست، دسترسی‌ها، کالکشن‌ها |
| `handlers-core.ts` | auth، users، students، teachers، classes، subjects، settings |
| `handlers-data.ts` | attendance، activities، grades، results، library، notifications، tasks، dashboard، backup |
| `api.ts` | روتر `/api/*` + صف همگام‌سازی آفلاین |
| `exports.ts` | چاپ/PDF، خروجی Word و Excel |

### کتابخانه‌های کمکی — `src/lib/`
`jalali.ts` (تقویم شمسی افغانی) · `grading.ts` (مکتسبه، اوسط، رتبه) · `types.ts`

### سایر
```
scripts/seed-github.mjs   # ساخت و پر کردن مخزن دادهٔ ابری
scripts/deploy-gh-pages.sh # انتشار سایت روی GitHub Pages
apk-build/                # پروژهٔ کامل APK اندروید (UI جاسازی‌شده + build.sh)
public/                   # لوگو، فونت وزیرمتن، manifest، Service Worker
```

## 🚀 راه‌اندازی برای توسعه‌دهندگان

```bash
# ۱) نصب
bun install          # یا npm install

# ۲) توکن مخزن داده (.env.local)
echo "NEXT_PUBLIC_GH_TOKEN=توکن-شما" > .env.local

# ۳) اجرا
bun run dev          # http://localhost:3000

# ساخت نسخهٔ استاتیک (برای Pages یا APK)
NEXT_OUTPUT=export NEXT_DIST_DIR=.nextprod NEXT_PUBLIC_BASE_PATH=/neda-al-qalam-school bun run build:static
```

### ساخت مخزن دادهٔ تازه (مکتب جدید)
```bash
GH_TOKEN=توکن node scripts/seed-github.mjs
```

### انتشار سایت روی GitHub Pages
```bash
GH_TOKEN=توکن bash scripts/deploy-gh-pages.sh
```

### ساخت APK اندروید
```bash
# ۱) رابط کاربری (نسخهٔ خصوصی با توکن داخلی):
NEXT_OUTPUT=export NEXT_DIST_DIR=.nextapk NEXT_PUBLIC_BASE_PATH=/assets \
  NEXT_PUBLIC_GH_TOKEN=توکن bun run build:static
# نسخهٔ عمومی: NEXT_PUBLIC_GH_TOKEN را خالی بگذارید

# ۲) APK (پیش‌نیاز: JDK 17+ و Android SDK platform 34 + build-tools 34.0.0):
export ANDROID_SDK_HOME=/path/to/android-sdk
bash apk-build/build.sh
# خروجی: download/nedaalqalam-school.apk
```

## ☁️ معماری — چطور کار می‌کند؟

```
┌─────────────┐   HTTPS (api.github.com)   ┌──────────────────────┐
│  APK اندروید │ ◄──────────────────────────► │  مخزن دادهٔ خصوصی     │
│  (UI داخلی)  │                              │ nedaalqalam-school-  │
└─────────────┘                              │        data          │
                                              │  db/*.json (۱۵ جدول)  │
┌─────────────┐   HTTPS                      │  + تاریخچهٔ کامل تغییرات│
│ سایت Pages   │ ◄──────────────────────────► └──────────────────────┘
│ (همیشه روشن) │
└─────────────┘
```

- همهٔ داده‌ها به‌صورت JSON در یک مخزن **خصوصی** گیت‌هاب ذخیره می‌شود (۱۵ فایل: users، students، grades، attendance، books و...)
- هر تغییر = یک **commit** با پیام فارسی (چه کسی، چه چیزی، چه زمانی) — سابقهٔ کامل و بازگشت‌پذیر
- رمزهای عبور با **scrypt** هش می‌شوند (هرگز ذخیرهٔ مستقیم نیست)
- تضاد همزمانی چند کاربر به‌صورت خودکار حل می‌شود (خواندن مجدد + اعمال تغییر)
- نسخهٔ قدیمی سرور-محور (Next.js API + SQLite) با تگ `server-version` در تاریخچه موجود است
