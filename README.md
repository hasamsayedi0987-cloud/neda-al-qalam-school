## ✨ امکانات

### نقش‌ها و دسترسی‌ها
| نقش | دسترسی |
|---|---|
| **مدیر** | دسترسی کامل: صنف‌ها، مضامین، معلمان، کارمندان، کاربران، گزارش‌ها، تنظیمات، پشتیبان‌گیری |
| **سرمعلم** | نظارت بر حاضری معلمان و شاگردان، تقسیم مضامین، تایید نمرات |
| **معلم** | حاضری صنف، ثبت فعالیت و نمرات مضمون خودش |
| **شاگرد / سرپرست** | مشاهدهٔ نمرات، حاضری، فعالیت‌ها و نتیجهٔ نهایی |
| **ملازم / کارمندان** | حاضری و وظایف محول‌شده |
| **کتابخانه** | ثبت کتاب‌ها، امانت دادن و پس گرفتن، تاریخ برگشت |

> 🔒 اگر مدیر یک کاربر را **غیرفعال یا حذف** کند، آن شخص دیگر به‌هیچ‌وجه نمی‌تواند وارد اپ شود (نشست فعال او نیز بلافاصله باطل می‌گردد).

### بخش‌های اصلی
- **صنف اول تا دوازدهم** + نگران صنف + تقسیم مضامین به معلمان
- **حاضری یومیه**: حاضر / غایب / مریض / رخصت + **گزارش ماهانه** با چاپ و Excel
- **فعالیت شاگردان**: کارخانگی، رفتار، شرکت در درس + امتیاز
- **نمرات**: تحریری، تقریری/عملی، کارخانگی، فعالیت صنفی برای دو دورهٔ **چهارو‌نیم‌ماهه** و **سالانه**
- **جدول نتایج خودکار**: همهٔ مضامین هر شاگرد در یک جدول با **مجموع، اوسط (دو رقم اعشار)، رتبه در صنف و نتیجه** — نمره‌ای که معلم ثبت می‌کند به‌صورت خودکار در جدول صنف و کارنامهٔ شاگرد منعکس می‌شود
- **کارنامهٔ دیجیتال** هر شاگرد با چاپ (PDF)، خروجی **Word** و **Excel**
- **کتابخانه**: کتاب‌ها، امانت، پس گرفتن، تاریخ برگشت و هشدار تأخیر

### نتیجهٔ خودکار
| نمرهٔ نهائی | مکتسبه |
|---|---|
| ۹۰ تا ۱۰۰ | الف |
| ۸۰ تا ۹۰ | ب |
| ۷۰ تا ۸۰ | ج |
| ۶۰ تا ۷۰ | د |
| ۵۰ تا ۶۰ | هـ |
| زیر ۵۰ | **تکرار صنف** |

نمرهٔ نهائی هر مضمون = میانگین نمرهٔ چهارو‌نیم‌ماهه و سالانه. اگر در یک مضمون نمرهٔ کمتر از ۵۰ باشد، نتیجهٔ کل شاگرد «تکرار صنف» می‌شود.

### آنلاین و آفلاین 📶
- اپ به‌صورت **PWA** نصب می‌شود (Add to Home Screen / Install) و مانند اپلیکیشن موبایل کار می‌کند.
- در حالت آفلاین، ثبت‌ها (نمره، حاضری، فعالیت...) در صف ذخیره شده و با وصل شدن مجدد **خودکار همگام** می‌گردند.

### امکانات دیگر
- رابط کاملاً **فارسی و راست‌به‌چپ** با **تاریخ شمسی** (نام ماه‌های افغانی: حمل، ثور، ...)
- رمز و ورود جداگانه برای هر کاربر + تغییر رمز + بازنشانی رمز توسط مدیر
- **پشتیبان‌گیری (Backup)** و بازیابی — بازیابی عمومی **تنها برای مدیر**
- **اعلان‌ها** برای معلمان و والدین (ثبت/تایید نمرات، غیبت شاگرد، اعلان دستی مدیر)
- لوگوی مکتب، بخش «دربارهٔ اپ و سازنده» با عکس و معلومات تماس

## 🚀 راه‌اندازی

### پیش‌نیاز
- Node.js 20+ یا [Bun](https://bun.sh)

### مراحل
```bash
# ۱) نصب وابستگی‌ها
bun install        # یا: npm install

# ۲) تنظیم متغیر محیطی
cp .env.example .env
# DATABASE_URL=file:/path/to/db/custom.db
# AUTH_SECRET=یک-رشته-تصادفی-طولانی

# ۳) ساخت دیتابیس
bun run db:push    # یا: npx prisma db push

# ۴) داده‌های اولیه (صنف‌ها، مضامین، حساب مدیر و نمونه‌ها)
bun scripts/seed.ts

# ۵) اجرا
bun run dev        # حالت توسعه — http://localhost:3000
bun run build && bun run start   # حالت production
```

## 📱 نصب به‌صورت اپ (PWA) و ساخت APK

1. **نصب مستقیم (پیشنهادی):** اپ را روی هاست اجرا کنید، سپس در موبایل با Chrome وارد شوید و «Add to Home screen / نصب برنامه» را بزنید — اپ تمام‌صفحه و با آیکون مکتب نصب می‌شود و آفلاین هم کار می‌کند.
2. **ساخت فایل APK (روش داخلی مخزن):** پوشهٔ `apk-build/` یک پروژهٔ اندروید سبک (WebView) با لوگوی مکتب دارد:

```bash
# پیش‌نیاز: JDK 17+ و Android SDK (platform 34 + build-tools 34.0.0)
export ANDROID_SDK_HOME=/path/to/android-sdk
bash apk-build/build.sh
# خروجی: download/nedaalqalam-school.apk
```

APK ساخته‌شده در اولین اجرا **آدرس سرور مکتب** را می‌پرسد (مثلاً `http://192.168.1.10:3000` در شبکهٔ مکتب یا آدرس هاست اینترنتی) و آن را ذخیره می‌کند. تغییر آدرس بعداً از دکمهٔ منوی گوشی ممکن است.
3. **روش جایگزین:** آدرس اپ را در سایت رایگان [PWABuilder.com](https://www.pwabuilder.com) وارد کنید و گزینهٔ Android (APK/AAB) را دانلود کنید.

## 🗂 ساختار پروژه

```
prisma/schema.prisma      # مدل‌های داده (کاربر، صنف، شاگرد، نمره، حاضری، کتابخانه...)
scripts/seed.ts           # داده‌های اولیه
apk-build/                # پروژهٔ APK اندروید (WebView + لوگو) و اسکریپت ساخت
src/lib/jalali.ts         # تبدیل تاریخ میلادی ↔ شمسی
src/lib/grading.ts        # منطق مکتسبه، نتیجه و رتبه‌بندی
src/lib/auth.ts           # احراز هویت (کوکی امضاشده HMAC + scrypt)
src/lib/client/api.ts     # لایهٔ شبکه با صف همگام‌سازی آفلاین
src/lib/client/exports.ts # چاپ/PDF، خروجی Word و Excel
src/app/api/*             # APIهای بک‌اند (auth, students, grades, results, library, ...)
src/components/app/*      # رابط کاربری (ورود، داشبورد، نمرات، نتایج، کتابخانه، ...)
public/manifest.json      # تنظیمات PWA
public/sw.js              # Service Worker (کش آفلاین)
```
